## Root Directory

```
mlamiBBQ/
├── .env                        ← Local environment variables (gitignored)
├── .env.example                ← Template for environment variables
├── .gitignore                  ← Git ignore rules
├── components.json             ← shadcn/ui component configuration
├── Dockerfile                  ← Container build definition (for self-hosting)
├── eslint.config.js            ← ESLint flat config
├── index.html                  ← HTML entry point (Vite injects bundle here)
├── nginx.conf                  ← Nginx config (for Docker / self-hosted deployments)
├── package.json                ← Node dependencies and scripts
├── package-lock.json           ← Locked dependency tree
├── postcss.config.js           ← PostCSS config (autoprefixer)
├── tailwind.config.ts          ← Tailwind design tokens and plugins
├── tsconfig.json               ← Root TypeScript config
├── tsconfig.app.json           ← App-specific TypeScript settings
├── tsconfig.node.json          ← Vite build tool TypeScript settings
├── vercel.json                 ← Vercel deployment config (rewrites + security headers)
├── vite.config.ts              ← Vite build, PWA, compression, code-splitting config
├── docs/                       ← ← YOU ARE HERE (official documentation)
├── dist/                       ← Production build output (gitignored)
├── node_modules/               ← Installed dependencies (gitignored)
├── public/                     ← Static assets served at root URL
│   ├── favicon.ico
│   ├── fonts/                  ← Self-hosted WOFF2 font files
│   └── images/                 ← Static images (logo, PWA icons)
├── scripts/                    ← Build or utility scripts
├── src/                        ← Application source code (see below)
└── supabase/                   ← Supabase backend configuration (see below)
```

## Key Architectural Conventions

### Naming Conventions

| Thing | Convention | Example |
|-------|-----------|---------|
| React components | PascalCase | `CookDashboard.tsx` |
| Hooks | camelCase with `use` prefix | `useKitchenRealtime.ts` |
| Types/interfaces | PascalCase | `AppRole`, `CartItem` |
| DB functions | snake_case | `complete_mpesa_payment` |
| DB tables | snake_case plural | `order_items`, `user_roles` |
| Edge functions | kebab-case | `mpesa-stk-push` |

### Import Aliases

The `@` alias resolves to `src/`:

```typescript
import { supabase } from '@/integrations/supabase/client';
import { hasPermission } from '@/lib/permissions';
```

Configured in `vite.config.ts:119-122` and `tsconfig.app.json`.
